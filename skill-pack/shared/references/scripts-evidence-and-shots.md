# 脚本、证据与镜头

## 目的
让每条内容用合适的脚本功能完成经营任务，并让重要主张能被事实、过程、比较或限定结果看见。

## 输入
定位、受众任务、候选选题、可用素材、产品资料、权利状态、拍摄资源和行动目标。

## 方法
1. 观点用于筛选判断同类，过程用于展示行动证据，知识用于降低判断成本，故事用于解释人物选择和变化。
2. 每条只保留一个核心思想，准备两个真实钩子变体，并让 CTA 与当前关系阶段匹配。
3. 建立主张—证据表：事实、可观察过程、公平比较、有限结果或删除；缺口进入 `reviewItems`。
4. 镜头先定义对象、关系、场景、意图和信息功能，再安排口播、直接证据、解释图层、字幕、声音和授权素材。

## 输出
`scriptStrategy`、`evidence` 和 `production` 的边界化方案；逐字口播交给 `content-voiceover-copywriter`，实际视频制作交给 `talking-head-video-production` 或 `video-use`。

## 证据边界
联想画面和情绪音乐不能证明事实；情景还原必须披露；对比需条件公平；健康、收入、平台效果等高风险主张需要合适来源和限制。

## 失败条件
多个中心、脚本类型只按个人偏好选择、重要主张无证据、虚构顾客与订单、偷拍、用复杂效果掩盖信息缺口。
