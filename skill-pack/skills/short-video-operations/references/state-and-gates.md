# 状态与门槛

- `intake`：目标或基础输入未齐。
- `positioning` / `planning`：商业、受众、素材、选题处理中。
- `script-ready`：脚本策略完成，重要主张尚需证据门。
- `production-ready`：证据与权利足够，可进入制作规划。
- `review-ready`：已有脚本、分镜或成片可审查。
- `publish-ready`：内容审查通过，但发布仍需明确授权。
- `measuring` / `reviewed`：采集可比数据或完成复盘。
- `completed`：约定的本地任务已交付，不代表外部行动已执行。
- `blocked` / `paused` / `superseded`：分别表示硬缺口、主动暂停或被新任务替代。

五类门槛：发布、付费支出、直播操作、全局安装、外部写入。批准必须记录动作、范围、上限、授权人和时间。
