# Short Video Script Strategy

## 核心原则
脚本类型服从经营任务：观点筛选判断同类，过程展示行动证据，知识降低判断成本，故事解释人物选择与变化。

## 触发与边界
用于四类脚本选择、结构设计、开篇方向、核心思想和 CTA 匹配。用户需要最终逐字稿、口播润色或发布文案时，路由 `content-voiceover-copywriter`；本 Skill 不代写完整逐字稿。

## 方法
1. 从选题与受众任务中确定单一 `coreIdea`。
2. 在观点、过程、知识、故事中选主功能；必要时只用一个辅功能。
3. 生成两个真实且正文可兑现的 `hookA` 与 `hookB`，说明各自假设。
4. 设计段落功能、转折、证据插槽和限制说明，不填造事实。
5. 判断 `CTA` 与关系阶段是否适配：理解、互动、咨询、购买或直播承接不能混为一体。
6. 输出给逐字稿 Skill 的事实包、禁写项和长度/语气约束。

## 输出契约
只写 `scriptStrategy`：`function`、`coreIdea`、`hookA`、`hookB`、`structure`、`evidenceSlots`、`CTA`、`ctaFit`、`copywritingRoute`。重要主张下一步必须进入证据规划。

## 常见错误
按个人风格偏好选脚本；一条塞多个中心；开篇承诺正文不兑现；CTA 跨越信任阶段；把模板当成用户事实。
