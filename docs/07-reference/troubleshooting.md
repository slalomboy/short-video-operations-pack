# 故障排查

## 找不到 Skill

先确认工具是否支持嵌套目录。若只扫描扁平目录，运行入口安装器到一个空目录，检查生成的 13 个托管 wrapper，再复制到目标位置。

## 补丁提示 stale

`baseVersion` 已落后。重新读取最新任务单，保留仍然有效的判断，基于新版本重新生成补丁；不要强制覆盖。

## 越权字段被拒绝

查看 `shared/field-ownership.json`，把写入交给字段拥有者 Skill。总控不能代写专业字段。

## 任务单校验失败

使用 `validate_job.py` 查看具体 JSON 路径。先修结构错误，再处理业务 reviewItems；不要只修渲染后的 Markdown。

## 无法进入投放或直播阶段

检查自然数据是否可比、转化链路是否明确、承诺是否可履约，以及支出/开播是否得到人工授权。门槛缺一不可。
