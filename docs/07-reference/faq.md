# FAQ

## 一定要跑完 13 个 Skill 吗？

不需要。总控根据入口状态选择最小链路；只改脚本就用脚本策略，需要跨定位、内容、实验和复盘时才启用总控。

## 它会自动发视频吗？

不会。它能生成发布实验和执行清单，但真实发布必须人工授权并由相应平台工具完成。

## 任务单为什么用 JSON？

JSON 可做 schema 校验、版本控制和补丁合并；Markdown 只用于阅读，避免两套事实源。

## 能保证爆款吗？

不能。它提高假设质量、协作一致性和学习速度，但平台分发、竞争和需求都存在不确定性。

## 48 条视频在哪里？

不在公开仓库。公开内容是独立编写的 Skill、教程、匿名案例和图解，不分发来源视频、逐字稿或逐条笔记。

## 可以商用吗？

代码和文档按 Apache-2.0 使用；你仍需自行确认素材版权、平台规则、广告合规、消费者权益和所在地区法律。
