# 7 条端到端实战流程

每条流程都使用最小必要 Skill 链，并把真实外部动作留在人工授权门之后。

- [新账号从定位到第一批选题](01-new-account-positioning.md)：先建立可验证定位，再生成首批低成本选题，避免一开始追求大而全。
- [把评论问题变成高价值选题](02-comment-to-topic.md)：保留评论原话和来源，用问题频率、业务价值、证据可得性共同排序。
- [从选题到可拍摄执行单](03-script-to-shoot.md)：脚本、证据、镜头与审查连续衔接，避免拍完才发现无法证明。
- [发现证据缺口时如何安全降级](04-evidence-gap.md)：把无证主张改为经验描述、条件式表达或直接停止，而不是补造证据。
- [从自然流量验证到小额投放](05-organic-to-paid.md)：先用同口径自然数据验证，再设置单变量预算和止损线；支出始终需要人工授权。
- [短视频到直播承接](06-video-to-live.md)：让短视频承诺、直播解释和实际履约一致，开播与优惠承诺都保持人工门。
- [周复盘回流素材与下一实验](07-weekly-review-loop.md)：只把可比数据中重复出现的模式沉淀为经验，并回流到素材卡和下一轮选题。
