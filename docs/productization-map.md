# 成品能力与双层产品化地图

[English](en/productization-map.md) · [返回中文首页](../README.md)

本页说明固定版本 `v0.1.0-alpha.4` 中真正可以独立完成结果的能力。稳定 ID 只用于跨文档追溯，不改变 13-Skill 套件结构。

| ID | 成品结果 | 最低输入 → 输出 | 免费领取物 | 套件升级 |
|---|---|---|---|---|
| `FIN-SV-000` | 从定位到发布实验与复盘的 13-Skill 运营链 | 业务目标、账号、受众、素材现状 → `ShortVideoOpsJob` 与阶段结果 | 13-Skill 内容运营链总览图 | PA 完整工作流、模板、案例与状态门 |
| `FIN-SV-001` | 账号定位卡 | 产品/能力、目标用户、经营目标 → 定位承诺、内容支柱与不做清单 | 账号定位一页卡 | PA 受众、选题、发布与复盘联动 |
| `FIN-SV-002` | 受众任务与顾虑卡 | 访谈、评论或搜索词 → 处境、任务、顾虑与判断标准 | 受众处境与顾虑采集表 | PA 样本库与选题联动 |
| `FIN-SV-003` | 有优先级的可拍选题清单 | 定位、受众、目标、证据 → 六维评分表 | 选题六维评分表 | PA 热点校准与内容批次 |
| `FIN-SV-006` | 内容证据与发布前修改单 | 脚本、分镜或成片信息 → 阻断项、证据缺口与修改动作 | 发布前 20 项审查表 | PA/PB 证据库与权利记录 |
| `FIN-SV-007` | 可执行拍摄与分镜清单 | 已确认脚本、画幅和素材 → 镜头、录屏、证据画面与素材任务 | 一页式拍摄分镜表 | PB VideoJob 与成片验收 |
| `FIN-SV-010` | 可检索、可判断权利的素材账 | 素材、来源与权利信息 → 素材卡、索引与复用边界 | 素材来源与复用登记表 | PA/PB 素材库与复用历史 |
| `FIN-SV-011` | 发布实验与数据复盘结论 | 已审内容、假设和真实数据 → 实验单、复盘与下一实验 | 单条视频发布实验与复盘表 | PA 批次实验库与周期复盘 |

这些能力可以独立调用，但共享父仓版本。付费增长与直播承接仍是套件内有界决策组件，不单列为已验证成品能力。

## 可验证边界

- 结构、路由、任务契约和确定性测试已验证。
- 没有用户样本时，受众和需求只能标为假设。
- 本仓库不登录账号、不上传、不发布、不授权投放，也不保证流量、转化或收益。
- 固定源码 Tag 不是 GitHub Release。
