# 六阶段学习路线

1. **理解系统**：先读能力边界和架构，知道总控不会代替专业判断。
2. **掌握任务单**：理解版本、字段所有权、reviewItems 和权限门。
3. **跑通内容链**：用定位→洞察→素材→选题→脚本完成第一条可审查内容。
4. **补齐证据与制作**：学会把主张变成证据矩阵，再转成拍摄执行单。
5. **建立实验**：在审查通过后设计单变量发布实验，统一数据窗口。
6. **经营增长闭环**：只对已验证内容考虑投放和直播承接，并把复盘结论回流素材库。

每个阶段至少完成一个匿名示例，再进入下一阶段。学习目标不是背 13 个名字，而是知道在什么状态调用最小必要 Skill。
