# Short Video Operations Pack

An open-source Agent Skills pack for running short-video operations as an evidence-aware, testable workflow instead of a collection of isolated prompts.

The pack contains one orchestrator, twelve specialist Skills, and a shared `ShortVideoOpsJob` contract. It covers positioning, audience insight, material management, topic planning, scripting, evidence, shooting, review, publishing experiments, paid growth, live conversion, and performance review.

Start with the [Chinese quick start](docs/01-getting-started/quick-start.md) or browse the [13 Skill manuals](docs/03-skills/README.md). External actions such as publishing, spending, or going live always require explicit human approval.

Current release: `v0.1.0-alpha.1` (prerelease). License: Apache-2.0.
